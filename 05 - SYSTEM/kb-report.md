# kb-report Skill

Answers questions using your Obsidian vault as the primary source — then saves every answer to a file. This is Steps 4 and 5 of the Karpathy method: "Q&A on Top of Your Own Knowledge Graph" + "Never Answer in Chat, Always Answer in Files."

## Core Rule

**Every answer = a file first, chat summary second.** If you only give the answer in chat, the session failed.

## Usage

```
/kb-report "Your question here"
```

## How It Works

1. **Parse the query** — identify topic, scope, expected output type
2. **Locate relevant files** — search vault for matching notes in `02 - AREAS/`, `01 - LITERATURE/`, `02 - PERMANENT/`
3. **Read all relevant files** — full content, not just snippets
4. **Synthesize** — write answer using ONLY vault content, cite sources inline
5. **Save to outputs/** — file named `YYYY-MM-DD_[Topic]_[Type].md`
6. **Link from wiki** — add `[[output-file]]` link to the relevant concept page in `02 - AREAS/`
7. **Chat summary** — 2-3 sentence summary of what was produced and where

## Example

**User asks:** "What is the actual evidence for Hatha Yoga being medieval, not ancient?"

```
/kb-report "What is the actual evidence for Hatha Yoga being medieval, not ancient?"
```

Claude:
1. Searches vault → finds `02 - AREAS/01 Philosophy & Religion/...yoga notes`
2. Reads relevant files
3. Saves to `05 - OUTPUTS/2026-07-13_Hatha-Yoga-Evidence_Report.md`
4. Links from relevant yoga wiki page
5. Summarizes in chat: "Saved to 05 - OUTPUTS/... Here's the 2-line answer: ..."

## When Vault Has No Answer

If the vault doesn't have enough information:
1. Write `05 - OUTPUTS/YYYY-MM-DD_[Topic]_GAPS.md` — note what IS in the vault, what's missing
2. Flag as "INSUFFICIENT — need more sources in 0-raw/"
3. Save anyway. Future queries can build on partial answers.

## Pitfalls

- **Don't answer from training data.** If the vault has it, use the vault. If it doesn't, say so clearly.
- **Don't leave the answer in chat.** Always save to `05 - OUTPUTS/` first.
- **Cite sources inline.** Every factual claim needs a `[[source note]]` link.
- **Wikilink everything.** The graph view only works if files link to each other.
