# Charvaka / Lokayata

## Overview
**Alternative Names**: Cārvāka, Lokāyata, Bārhaspatya, Nāstika  
**Founder**: Bṛhaspati (legendary; attributed Bṛhaspati Sūtra, now lost)  
**Date**: ~6th c. BCE – 12th c. CE (last references)  
**School**: Materialist, anti-Vedic, skeptical

## Core Tenets

| Tenet | Description |
|-------|-------------|
| **Materialism** | Only four elements (earth, water, fire, air); no ākāśa (space) |
| **Epistemology** | Pratyakṣa (perception) primary; inference limited to verifiable causation |
| **Anti-Vedism** | Rejection of śabda-pramāṇa (scriptural authority), afterlife, karma, soul (ātman) |
| **Ethics** | This-worldly wellbeing, not hedonism (hedonism is a Brahminical distortion) |

## Key Epistemological Distinction

The claim that Cārvākas "rejected inference entirely" is an **opponent caricature**. Current scholarship distinguishes:

1. **Perception-only for metaphysics**: Rejected inference for afterlife/god/soul (not grounded in verifiable perception)
2. **Inference for mundane causation**: Likely accepted fire-from-smoke type inference
3. **Jayarāśi's radical skepticism**: Questions even perception itself — skeptical, not materialist position

## Pre-Cārvāka Materialism
5-element system (earth, water, fire, air, space) referenced in **Maṇimēkalai** (~6th c. CE, Tamil). Suggests South Indian materialist tradition preceding classical Cārvāka.

**Ajita Keśakambala** (~5th c. BCE, contemporary of Buddha) — earliest named materialist in Buddhist texts (Sāmaññaphala Sutta).

## Why No Institutional Survival?
- No monastic institution (no saṅgha)
- No royal patronage post-Gupta
- Active suppression (Manusmṛti legalizes nāstika exclusion)
- Absorbed into Tantra; lost distinct identity
