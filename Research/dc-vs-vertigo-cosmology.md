# DC vs Vertigo Cosmology: Layer-by-Layer Comparison

> **Source:** Wikipedia research (Multiverse_(DC_Comics), The_Endless_(comics), Lucifer_(DC_Comics))

## Overview

| Aspect | DC Mainline | Vertigo |
|--------|-------------|---------|
| **Type** | Physical/narrative | Theological/mythological |
| **Focus** | Geometric dimensions, multiverse mechanics | Divine will, consciousness, Creation |
| **Creator** | The Presence (transcendent) | The Unknowable → The Presence |
| **Key Theme** | Stories as reality, Monitor-tier beings | Conceptual eternity, Endless as pillars |

---

## DC Mainline Cosmology

**Flow:** The Presence → The Overvoid (blank page) → The Great Darkness (void within) → The Source (Light of Creation) → The Hands/Perpetua → The Monitors → The Multiverse

| Layer | Name | Description |
|-------|------|-------------|
| **0** | The Presence / God Beyond Gods | Supreme non-dual being who transcends all |
| **1** | The Overvoid | Empty nothingness, "blank page" of fiction |
| **2** | The Great Darkness | Primordial void within the Overvoid |
| **3** | The Source / Light of Creation | Creative energy emerging from Darkness |
| **4** | The Hands / Perpetua | Cosmic beings creating multiverses |
| **5** | The Monitors | Oversighters from the Overvoid, outside narratives |
| **6** | The Multiverse | 52+ universes on vibrational planes |
| **7** | Everything else | Gods, heroes, cosmic entities |

## Vertigo Cosmology

**Flow:** The Unknowable → The Presence (Yahweh) → The Void (God's mind) + The Great Darkness (shadow) → Michael/Lucifer (archangels) → Mother Night/Father Time → The Endless → Creation

| Layer | Name | Description |
|-------|------|-------------|
| **0** | The Unknowable / The Absolute | True Godhead beyond all duality |
| **1** | The Presence / Yahweh | Active personal Creator |
| **2** | The Void | God's mind, blank canvas |
| **2.5** | The Great Darkness | God's shadow, co-eternal but derivative |
| **3** | The Silver City / Heaven | First Creation |
| **4** | Michael & Lucifer | Demiurgic archangels |
| **5** | Mother Night & Father Time | Pre-Creation conditions |
| **6** | The Endless | Dream, Death, Destiny, etc. - bound to Creation |
| **7** | Everything else | Gods, demons, mortals |

## Key Divergences

### 1. Hierarchy Above the Presence
- **Vertigo:** Has "The Unknowable" — a tier above even Yahweh
- **Mainline DC:** The Presence is absolute ceiling

### 2. Origin of Darkness
- **Vertigo:** The Presence created both Light and Shadow
- **Mainline DC:** Darkness existed first, birthed the Light

### 3. Nature of Key Figures
- **Lucifer/Michael (Vertigo):** Created beings just below the Presence; can create universes
- **Monitors/Perpetua (Mainline):** Exist *outside* creation in the Overvoid

### 4. The Endless vs Monitors
- **The Endless:** Conceptual forces *bound to* Creation (Death must claim all)
- **The Monitors:** Exist *outside* narratives, overseeing from the Overvoid

---

## Power Scaling Verdict

**Numerically:** Vertigo's cosmology scales higher
- Lucifer: Creates his own universe, rivals godhood
- Michael: Demiurgic power = Creation itself
- The Endless: Exist beyond mortal comprehension

**Functionally:** They're incompatible systems
- DC mainline: Dimensional/vibrational, can be "argued" with
- Vertigo: Metaphysical/conceptual, fundamental to existence
