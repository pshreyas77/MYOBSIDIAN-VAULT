**For future Claude:** Anthony & Ringe 2015 is solid but incomplete. Your migration argument relies on linguistics — this MOC lets you evaluate OIT linguistic claims rigorously. Connects to `Research/Deep/2026-06-22 — Aryan Migration Debate Evidence and Pre-Aryan India.md`.

## 1. Core Methods

| Concept | Explanation | Application to Your Vault |
|---------|-------------|---------------------------|
| **Comparative Method** | Reconstruct proto-language via systematic sound correspondences across daughter languages | PIE reconstruction; Indo-Iranian subgrouping |
| **Internal Reconstruction** | Reconstruct older stages within a single language using morphological alternations | Sanskrit internal reconstruction (e.g., dṛś- / darś- alternations) |
| **Loanword Identification** | Requires: phonological adaptation, distribution across languages, semantic field, cultural context | Mitanni IA loanwords; Rigvedic non-IA substrate |
| **Subgrouping** | Tree model (shared innovations) vs wave model (areal diffusion) | Indo-Iranian is robust; Indo-Aryan vs Iranian clear; areal features complicate |
| **Sound Laws** | Grimm's Law, Verner's Law, Brugmann's Law, Bartholomae's Law, Grassmann's Law | Brugmann's Law (PIE o → a in Indo-Aryan) is key evidence for Indo-Aryan unity |
| **Laryngeal Theory** | Reconstructs PIE laryngeal consonants (h₁, h₂, h₃) | Standard in modern PIE reconstruction; explains Sanskrit i-stems, reduplication |

## 2. Key Evidence for Aryan Migration (Linguistic)

| Evidence | Details |
|----------|---------|
| **Mitanni Indo-Aryan (~1350 BCE)** | Hittite/Kassite/Akkadian texts with IA divine names (Indra, Mitra, Varuna, Nasatya) and horse-training terms (aśva, vartana). **This is NOT Sanskrit — pre-Vedic IA.** |
| **Rigvedic loanwords** | Non-IA substrate words for flora, fauna, agricultural implements suggestive of Harappan language |
| **Iranian-Indo-Aryan isoglosses** | Shared innovations separate them from other IE branches |

## 3. OIT Linguistic Claims: Evaluation

Out of India Theory linguistic arguments fail on:

| Failure | Explanation |
|---------|-------------|
| **No sound law explanation** | OIT proponents cannot explain why European languages share innovations that Indo-Aryan lacks |
| **No substrate explanation** | If IE spread from India, European languages should show Indian substrate — they don't |
| **Chronology problem** | Mitanni IA is ~1350 BCE in Syria; Rigvedic Sanskrit is philologically reconstructed to 1500–1200 BCE. OIT requires impossible chronology. |
